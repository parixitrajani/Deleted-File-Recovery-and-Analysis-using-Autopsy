**Project Description**

This project demonstrates how deleted files can be recovered and analyzed using Autopsy, a digital forensic tool. It simulates a real-world investigation scenario where digital evidence is extracted and examined to understand user activity.

**Objectives**

Recover deleted files from a storage device,
Analyze file metadata and timestamps,
Understand user activity through recovered data,
Gain practical knowledge of digital forensic tools.

**Tools Used**

Autopsy (Digital Forensic Tool)

**Project Scope**

This project focuses on recovering deleted files and analyzing them using Autopsy. It includes file recovery, metadata analysis, and basic timeline understanding.

**Limitations**

Does not include memory forensics,
Does not include network forensics,
Limited to basic file recovery techniques.

**Methodology**

**1. Autopsy Installation**

Download Autopsy from the official website
Install using setup wizard
Launch the application

**2. Case Creation**

Open Autopsy
Click on New Case
Enter case name and base directory

**3. Add Data Source**

Select data source type (USB / Disk / Image)
Choose the storage device
Proceed to next step

**4. Configure Ingest Modules**

Select required modules such as:
File Type Identification
Keyword Search
Recent Activity
Start analysis

**5. Data Analysis**

Explore file system
Navigate to Deleted Files section
Examine file details and metadata

**6. File Recovery**

Select deleted file
Click on Extract File
Save recovered file to system

**Analysis**

The deleted files were successfully recovered from the USB device.
The recovered data includes images and documents.
File details such as name, type, size, and timestamps were analyzed.
This demonstrates that deleted data can still be accessed and examined using forensic tools.

**Findings**

Deleted files can be recovered.
Data is not permanently deleted.
File metadata helps in investigation.
User activity can be analyzed.

**Conclusion**

Autopsy is an effective digital forensic tool for recovering deleted files and analyzing digital evidence.
This project highlights the importance of forensic tools in investigating digital data.
